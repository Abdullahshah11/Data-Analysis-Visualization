# Week 04 - Data Analysis & Visualization

## Objective

The objective of this Week 04 task is to perform basic data analysis and visualization using Python.

## Tools & Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Missingno
- YData Profiling

## Tasks Performed

1. Load the dataset using Pandas.
2. Explore the dataset.
3. Check the number of rows and columns.
4. Check column names and data types.
5. Identify missing values.
6. Handle missing values.
7. Analyze the age distribution.
8. Create a bar chart.
9. Create a pie chart.
10. Create a scatter plot for Views vs Likes.
11. Perform basic data visualization.

## Files

- `week04.ipynb` - Google Colab notebook containing the complete Week 04 task.
- `Activity 01 (Responses).csv` - Dataset used for the analysis.
- `README.md` - Project documentation.

## How to Run

1. Open `week04.ipynb` in Google Colab.
2. Upload `Activity 01 (Responses).csv`.
3. Run the notebook cells from top to bottom.
4. View the generated analysis and visualizations.

## Output

The notebook generates different visualizations including:

- Age distribution
- Bar charts
- Pie charts
- Views vs Likes scatter plot
